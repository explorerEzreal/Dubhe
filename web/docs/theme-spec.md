# Bubhe 天枢 · 主题系统 v2 设计规范

## 一、问题诊断

优化前「单调」不是配色丑，而是**没有色彩体系**：

| 问题 | 优化前 | 后果 |
| --- | --- | --- |
| 侧栏硬编码纯灰 | `#202020` / `#f0f0f0` | 面积最大的区域零色彩倾向 |
| 背景层级塌陷 | `colorBgLayout` ≈ `colorBgElevated` | 卡片浮不起来，全屏一片平 |
| 深色为中性灰阶 | antd 默认算法输出 | 无色偏，缺氛围 |
| 强调色单一 | 全局仅 1 个 `#00c29a` | 无主次对比 |
| ECharts 脱离主题 | 颜色全部硬编码 | 深色下图表发灰发闷 |
| 语义色分裂 | success 有 3 个版本 | 视觉不一致 |

## 二、设计方向

- **主色**：翡翠青 Teal（延续原品牌绿色基因，提饱和度）
- **深色基底**：深青墨（明确色彩倾向，非纯灰、非纯黑）
- **视觉强度**：鲜明现代（渐变标识 + 柔和阴影 + 选中态发光），不干扰数据阅读

## 三、单一色彩来源

新增 `src/styles/theme.ts` —— 全系统唯一色彩来源，同时供给 antd token、CSS 变量、ECharts 三处消费。

```
theme.ts ──┬── providers.tsx ── antd ConfigProvider token + 组件级 token
           ├── toCssVars()   ── :root CSS 自定义属性（global.less 消费）
           └── useChartTheme() ── ECharts 系列色 / 坐标轴 / 提示框
```

## 五、鲜明现代的具体手法

1. **品牌渐变标识** —— logo、头像、发送按钮用 `135deg teal→cyan` 渐变 + 品牌色阴影
2. **卡片柔和阴影** —— 浅色 `0 1px 2px rgba(15,23,42,.04), 0 4px 16px rgba(15,23,42,.06)`，深色改用更重的黑投影
3. **选中态发光** —— 侧栏选中项左侧 3px 渐变指示条 + 品牌色阴影，配淡青底 + 品牌色文字
4. **层次化选中** —— 导航项 hover 用中性底，选中才用品牌色，两级区分
5. **图表跟随主题** —— 坐标轴、分割线、提示框背景全部随模式切换

## 六、间距与圆角

- 圆角：`10px` 基础 / `8px` 小组件 / `14px` 大容器（沿用原有 `borderRadius: 10`）
- 侧栏宽 `320px`，折叠 `68px`；控制高度 `34px`
- 卡片内边距 `20px`，KPI 卡 `16px`
- 栅格间距：`16px` 主栅格、`12px` 卡片组、`10px` 紧凑列表

## 七、多端适配

现有断点保留：`1450 / 1000 / 900 / 768 / 620 / 540 / 390 px`。
深色模式额外处理：阴影改为纯黑投影（青色阴影在深底上发脏）、图表面积色用 hex8 透明度、tooltip 跟随表面色。

**窄屏（≤900px）** 侧栏自动折叠、卡片栅格降列、图表 `min-width: 0` 防溢出 —— 已保留。

## 九、可访问性

- 正文 / 次要 / 三级文字均达 WCAG AA（4.5:1）以上
- 主按钮白字对比 3.8:1，满足大文本与 UI 组件 3:1 要求；若需严格正文级，可将按钮底色换为 `#0F766E`
- 状态不依赖单一颜色传达：状态点 + 文字标签 + 左边框三重编码
- `color-scheme` 随模式同步，原生滚动条与表单控件自动适配
